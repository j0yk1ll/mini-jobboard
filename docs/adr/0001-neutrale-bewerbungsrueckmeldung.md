# Einheitliche Rückmeldung für Erst- und Wiederholungsbewerbungen

Das öffentliche Bewerbungsformular antwortet auf eine gültige Erstbewerbung und eine gültige Wiederholungsbewerbung auf dieselbe offene Stellenanzeige mit „Deine Bewerbung liegt vor“. Pro Stellenanzeige und normalisierter E-Mail-Adresse wird nur die erste Bewerbung gespeichert. Eine ausdrückliche Duplikatmeldung wäre für Bewerber klarer, könnte aber Dritten verraten, ob zu einer fremden E-Mail-Adresse bereits eine Bewerbung vorliegt.
